# Declaración de uso de IA

La IA se usó únicamente para:

## 1. Organización de información y archivos

Ordenar las notas del proyecto y los nombres de las capturas de las pruebas.

> Ordena estas notas y propone una convención de nombres para las capturas de las pruebas.

## 2. Script de los 20 datos de prueba

Generar un script de consola que guarda 20 tareas de prueba en localStorage.

> Escribe un script de consola que guarde 20 tareas de prueba en localStorage, en la clave `taskmanager.tasks`, con prioridades, estados y fechas distintas.

## 3. Verificación de código

Revisar los módulos para detectar errores.

> Revisa estos módulos y señala errores o casos no controlados. No reescribas el código.

## 4. Sugerencia de pruebas adicionales

Proponer pruebas manuales que no estaban en el plan.

> Sugiere pruebas manuales adicionales para esta funcionalidad.
